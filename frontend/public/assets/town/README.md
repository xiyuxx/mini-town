# Town Map Assets

This directory contains the runtime sprite sheets used by the PixiJS town map.

- `kenney-rpg-urban.png` is from Kenney's RPG Urban Pack 1.0.
  Source: https://kenney.nl/assets/rpg-urban-pack
- `kenney-roguelike-rpg.png` is from Kenney's Roguelike/RPG Pack.
  Source: https://kenney.nl/assets/roguelike-rpg-pack

Both packs are licensed under Creative Commons Zero (CC0) 1.0. Their original
license texts are included alongside the sprite sheets.
